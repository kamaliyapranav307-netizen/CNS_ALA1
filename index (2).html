📚 Encryption Details

AES

AES-GCM

Symmetric encryption used to protect the actual message.

RSA

RSA-OAEP

Asymmetric encryption used to securely protect the AES key.

Key Size

AES 256-bit + RSA 4096-bit

AES key is 256-bit (the maximum size supported by the AES standard). The RSA key pair that wraps it is 4096-bit, generated fresh by the browser on load.

Security

Web Crypto API

Cryptographic operations are performed by the browser.
